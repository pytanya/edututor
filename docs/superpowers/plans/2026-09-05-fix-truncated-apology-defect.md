# Дефект: «Извините, ответ получился слишком длинным…» вместо ответа на короткий вопрос

> **For agentic workers:** Tasks use checkbox (`- [ ]`) syntax. Execution is inline
> in this session. **Коммиты не выполняются** без явной просьбы (AGENTS.md).

**Goal:** Убрать ложное срабатывание вежливого отказа-обрыва в диалоге с
репетитором. Ученик пишет короткую директиву (например, «да» или «давай решим
пару примеров, чтобы закрепить правило про разные знаки?»), а репетитор вместо
нормального продолжения занятия отвечает:

> «Извините, ответ получился слишком длинным и оборвался. Сформулируйте вопрос
> короче или разбейте его на несколько сообщений.»

**Repro (из наблюдения):**
1. Диалог по теме (например, сложение чисел с разными знаками), открыт quiz/practice.
2. Ученик соглашается решить ещё примеры короткой фразой.
3. В чат приходит текст `_TRUNCATED_FALLBACK_TEXT` из `src/agent/loop.py`
   (добавлен как защита от показа сырого JSON при обрыве ответа).

## Root-cause (гипотезы)

Фолбэк срабатывает в `AgentRuntime.finalize` (`src/agent/loop.py`), когда:
- `parse_content_envelopes(raw)` вернул пусто,
- `salvage_truncated_envelope(raw)` вернул `None`,
- но `looks_like_truncated_envelope(raw)` — True (ответ начинается с `{"type": …`).

Возможные причины именно на коротких ходах:
1. **Оборванный quiz/practice**: модель начала большой quiz-конверт (вопрос +
   4 варианта + `_correct_answer`), ответ упёрся в `max_tokens` и оборвался.
   `salvage` осознанно не спасает quiz/practice → отказ. Причины обрыва:
   reasoning-модели (deepseek v4-flash тратит бюджет на «размышления») или просто
   большой вывод при `llm_max_tokens`.
2. **Cascade-фолбек**: если основная модель вернула пусто/обрыв, каскад пробует
   запасную; последняя попытка тоже может дать незакрытый конверт → отказ.
3. **Нет повтора финализации**: после обрыва агент НЕ пробует перегенерировать
   ответ (нет retry-шага «продолжи с места обрыва»), сразу вежливо сдаётся.

Усугубляет: отказ не учитывает «короткость» запроса — он не должен возникать на
согласии «да» / «давай ещё примеры», где требуемый ответ короткий.

## Constraints

- Не показывать ученику сырой JSON-«словарь» ни при каких обстоятельствах.
- Отказ — последнее средство; сначала одна попытка восстановления.
- Все LLM-вызовы в пределах существующих бюджета/лимитов; fail-soft.
- Запуск тестов из `adaptive_tutor/`:
  `.venv/Scripts/python.exe -m pytest tests/<file> -q`; стиль: `ruff check <file>`.
- Коммит только по явной просьбе.
